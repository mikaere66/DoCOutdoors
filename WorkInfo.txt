
To retrieve WorkInfo from WorkManager within a Jetpack Compose application, you typically observe the WorkInfo using LiveData or Flow. This allows your Composable to react to changes in the work's state, progress, or output data.
Here's how to compose a function to get WorkInfo:
Kotlin

import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.livedata.observeAsState
import androidx.compose.ui.platform.LocalContext
import androidx.work.WorkInfo
import androidx.work.WorkManager
import java.util.UUID

@Composable
fun observeWorkInfo(workRequestId: UUID): WorkInfo? {
    val context = LocalContext.current
    val workManager = WorkManager.getInstance(context)

    // Observe the LiveData<WorkInfo> returned by getWorkInfoByIdLiveData
    val workInfoLiveData = workManager.getWorkInfoByIdLiveData(workRequestId)
    val workInfo by workInfoLiveData.observeAsState()

    return workInfo
}
Explanation:
@Composable fun observeWorkInfo(workRequestId: UUID): WorkInfo?: This defines a Composable function that takes the UUID of your WorkRequest as input and returns a nullable WorkInfo object.
val context = LocalContext.current: This line obtains the current Context within the Composable, which is necessary to get an instance of WorkManager.
val workManager = WorkManager.getInstance(context): This retrieves the singleton instance of WorkManager.
val workInfoLiveData = workManager.getWorkInfoByIdLiveData(workRequestId): This is the core of retrieving WorkInfo. getWorkInfoByIdLiveData() returns a LiveData<WorkInfo> that will update whenever the state or data of the specified WorkRequest changes.
val workInfo by workInfoLiveData.observeAsState(): This is a Jetpack Compose extension function that allows you to observe a LiveData and convert its value into a State object that Compose can react to. When the LiveData emits a new WorkInfo, the workInfo variable will be updated, triggering a recomposition of any Composable that uses it.
return workInfo: The function returns the current WorkInfo object, which can be null if the LiveData hasn't emitted a value yet or if the WorkRequest with the given ID doesn't exist.
How to use it in another Composable:
Kotlin

import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.work.WorkInfo
import java.util.UUID

@Composable
fun MyWorkStatusDisplay(workRequestId: UUID) {
    val workInfo = observeWorkInfo(workRequestId)

    when (workInfo?.state) {
        WorkInfo.State.ENQUEUED -> Text("Work is enqueued")
        WorkInfo.State.RUNNING -> Text("Work is running")
        WorkInfo.State.SUCCEEDED -> Text("Work succeeded!")
        WorkInfo.State.FAILED -> Text("Work failed.")
        WorkInfo.State.CANCELLED -> Text("Work was cancelled.")
        WorkInfo.State.BLOCKED -> Text("Work is blocked.")
        null -> Text("Work status unknown.")
    }

    // You can also access progress or output data if available
    workInfo?.progress?.let { progressData ->
        val progress = progressData.getInt("Progress", 0)
        Text("Progress: $progress%")
    }
}
