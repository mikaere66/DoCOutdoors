# DoC Outdoors

The DoC Outdoors app is intended to provide simple and
straightforward listings of the various New Zealand Department of
Conservation assets that are maintained for public leisure. As well as
Campsites, Huts, and Tracks, there's a list of Alerts, which brings to
light any current closures and/or hazards on DoC sites. These alerts can
be updated automatically within the app, either daily or weekly.
